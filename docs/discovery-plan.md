# Discovery plan

**No customer research has been done for this concept.** This is the plan I would run in week one. It lists questions and what would change the plan, not findings.

## Questions to answer

| # | Question | Method | What would change the plan |
|---|---|---|---|
| D1 | Who writes the synthesis, and who is blamed when it's wrong? | 6–8 calls with associates/VPs at funds and consultancies already using Junior | If the VP writes it, the reviewer and approver are the same person and the gate needs a different shape |
| D2 | How do teams check claims against calls today? | Ask for a walk-through of the last brief they sent (screen share, no confidential data) | If they already re-read transcripts reliably, the value is speed, not safety |
| D3 | How often does a wrong figure or overgeneralisation reach a VP or IC? | Ask for recalled incidents in the last quarter; don't prompt with examples | If rare, position as speed and defensibility, not error prevention |
| D4 | Which checks matter? | Show the check list and ask them to rank; watch reactions to the comparison table | Drop or downgrade checks nobody values to cut review fatigue |
| D5 | Do cohort-vs-contradiction distinctions match their mental model? | Card sort with 10 synthetic quote pairs | If they split differently, change the scope taxonomy |
| D6 | Would they use a template-based guide, or do they want free generation? | Show guide; ask them to edit it for a real next call | If they rewrite everything, templates are too generic |
| D7 | What must never leave the deal team? | Ask compliance-minded users what they redact today | Redaction defaults and warning copy |
| D8 | Where in Junior should this live: per call, per project, or in Alexandria? | Concept test with 3 placements | Placement and entry point |

## Product-usage questions (for Junior's own data, if available)

- How many projects have more than one call? Median calls per project?
- How often are summaries or takeaways exported or copied?
- How often do users open a transcript from a cited insight?

## Guardrails

- Recruit only through Junior's normal customer channels, with consent.
- Don't collect deal-identifying details; use the synthetic project as the prop.
- Record findings separately from assumptions. Update [decision-log.md](decision-log.md) when a decision changes.
