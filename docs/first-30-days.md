# First 30 days (if I joined as Senior PM, London)

## Days 1–10: learn

- Shadow customer calls with PE and consulting users; read recent support tickets on transcripts, summaries and sharing.
- Map the research workflow end to end with engineering and design; agree on where errors enter (ASR, entity, synthesis, copy-paste).
- Pull usage: calls per project, transcript opens from insights, export and share rates.
- Run the discovery plan's first 6 interviews ([discovery-plan.md](discovery-plan.md)).

## Days 11–20: decide

- Write a one-page bet for the evidence-review gate using real data and interview notes. Mark which assumptions held.
- Agree success metrics, denominators and a baseline-measurement window with data/eng.
- Define the launch checklist and triage rotation for the weekly ship cadence.

## Days 21–30: ship

- Ship the smallest production slice behind a flag (likely: citation coverage plus the source-click drawer on the synthesis view).
- Start the pilot with 2–3 teams and set up weekly metrics review.
- Publish a decision log so engineering and design can see what changed and why.
