# ELI5

When three people tell you about a shop, you write a note for your parent: "the shop raised prices 7%".

Evidence Review is a friend who checks your note before you hand it over:

- "Who said that? Show me." If nobody said it, the note can't go yet.
- "They said 12%, not 15%."
- "That person only talked about the small shops, but you wrote 'all shops'."
- "Two people said different numbers about the same thing. That's a real disagreement. Ask again."
- "This person was talking about a different group, so that's not a disagreement."

Then it helps you write fair questions for next time, like "what did you see?" rather than "surely it went up, right?".

You decide what's right. The friend only makes sure you looked.
